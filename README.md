# Clickr Landing Page

> A responsive business landing page developed as part of a Front-End Development course at Aulab Academy. 

---

## 📌 Overview
This project was developed during a Front-End Development course at Aulab Academy.

The goal was to recreate an existing landing page design using HTML, CSS, Bootstrap, and JavaScript in order to practice responsive web development, UI implementation, and front-end programming concepts.

All code was written from scratch as part of the learning process.

---

## 🚀 Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Font Awesome
- Google Fonts

---

## ✨ Features

- Responsive navigation bar
- Animated image gallery
- Testimonials slider
- Service showcase section
- Pricing packages
- FAQ section
- Modern and clean UI
- Mobile-friendly layout

## ▶️ Running the Project

1. Clone the repository:

```bash

```

2. Open the project folder.

3. Launch `index.html` in your browser.

No installation is required.
